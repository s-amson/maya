# Happy Birthday Belinda 💖

A cute, animated **birthday website** made with ❤️ for Belinda.

## ✨ Tech Stack
HTML5, CSS3 and JavaScript (canvas-confetti for the confetti).

## 🔧 Customize
1. Open `index.html` to change any text or captions.
2. Replace the pictures in the `img` folder, keeping the same file names:
   - `user.JPEG` is the portrait at the top of the page.
   - `1.JPEG` to `4.JPEG` are the memory photos (square photos look best).
3. Add your song: put an MP3 named `fav.mp3` in the same folder as `index.html`. It plays in the background and loops. The bar at the top of the page shows the song name with Pause and Mute buttons.
4. Open `index.html` in a browser to preview, or host the folder on GitHub Pages, Netlify or Vercel and share the link.
